# KpitTyping - Система тестирования скорости печати

## Описание
KpitTyping - это веб-приложение для тестирования скорости печати с различными уровнями сложности и системой учета результатов. Приложение позволяет:
- Тестировать скорость печати на разных уровнях сложности
- Сохранять и отслеживать результаты
- Просматривать таблицу рекордов
- Управлять результатами через панель учителя

## Установка

### Предварительные требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаги установки
1. Клонировать репозиторий:
```bash
git clone https://github.com/your-username/kpit-typing.git
cd kpit-typing
```

2. Создать виртуальное окружение:
```bash
python -m venv venv
```

3. Активировать окружение:
- Windows:
```bash
venv\Scripts\activate
```
- Unix/MacOS:
```bash
source venv/bin/activate
```

4. Установить зависимости:
```bash
pip install -r requirements.txt
```

5. Сгенерировать секретные ключи:
```bash
python generate_secrets.py
```

6. Создать файл `.env`:
```bash
cp .env.example .env
```
Отредактируйте `.env` файл, вставив сгенерированные ключи и настроив другие параметры.

7. Запустить приложение:
```bash
python app.py
```

## Конфигурация

### Переменные окружения
- `SECRET_KEY` - секретный ключ Flask
- `JWT_SECRET` - секретный ключ для JWT
- `TEACHER_USERNAME` - имя пользователя для учителя
- `TEACHER_PASSWORD` - пароль учителя
- `FLASK_ENV` - окружение (development/production/testing)

### Уровни сложности
- Легкий
- Нормальный
- Продвинутый
- Экспертный

## API Endpoints

### Результаты
- `GET /api/scores` - получить все результаты
- `POST /api/save-score` - сохранить новый результат
- `DELETE /api/delete-score/<score_id>` - удалить результат
- `POST /api/clear-scores` - очистить все результаты

### Аутентификация
- `POST /api/login` - вход в систему
- `GET /api/check-auth` - проверка авторизации
- `POST /api/logout` - выход из системы

## Безопасность
- Все секретные ключи хранятся в переменных окружения
- Используется JWT для аутентификации
- Защита от XSS и CSRF атак
- Безопасное хранение паролей

## Разработка
Для разработки рекомендуется использовать режим development:
```bash
export FLASK_ENV=development
python app.py
```

## Продакшн
Для продакшена:
1. Установите `FLASK_ENV=production`
2. Используйте HTTPS
3. Настройте прокси-сервер (например, Nginx)
4. Используйте Gunicorn для запуска:
```bash
gunicorn app:app
```
